# Онбординг школьного психолога (Республика Татарстан)

Единый справочник для педагога-психолога школы: нормативная база РФ и Республики Татарстан, документация, шаблоны, инструкции по направлениям работы.

**Сайт:** https://qbic1.github.io/psycho-onboarding/

## Разделы

- **Начало работы** — первые дни в школе, правовой статус должности, кабинет.
- **Нормативная база** — федеральные законы и приказы, региональная специфика РТ.
- **Документация** — план работы, журнал учёта, отчётность, персональные данные.
- **Шаблоны** — согласия, заключения, карты сопровождения, документы ППк/ПМПК.
- **Файлы для скачивания** — 10 шаблонов типовых документов в формате .docx ([раздел на сайте](https://qbic1.github.io/psycho-onboarding/docs/templates/download)); исходник генерации — `scripts/generate-templates.js`.
- **Направления работы** — диагностика, консультирование, коррекция, ППк, СПТ, кризисное реагирование, границы компетенции.
- **Контакты** — службы Республики Татарстан.

## Разработка

Сайт построен на [Docusaurus 3](https://docusaurus.io/). Контент — Markdown в каталоге `docs/`.

```bash
npm install        # установка зависимостей
npm start          # dev-сервер с hot reload
npm run build      # production-сборка в build/
npm run serve      # локальный просмотр сборки
```

Публикация на GitHub Pages выполняется автоматически через GitHub Actions (`.github/workflows/deploy.yml`) при пуше в ветку `main`.

## Вклад

Нашли неточность, устаревший реквизит или хотите добавить раздел — создайте issue или pull request. Перед ссылками на нормативные акты в своих документах всегда проверяйте действующую редакцию в официальных источниках.
