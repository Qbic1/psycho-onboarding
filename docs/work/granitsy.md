# Границы компетенции

Чёткое понимание границ — профессиональная защита психолога и качество помощи детям.

## Психолог ОБЯЗАН

- Оказывать ППМС-помощь в рамках ст. 42 273-ФЗ и [профстандарта](https://www.consultant.ru/document/cons_doc_LAW_183257/).
- Получать согласие на работу с ребёнком и соблюдать конфиденциальность (кроме угрозы жизни).
- Сообщать об угрозе жизни и здоровью ребёнка в уполномоченные инстанции.
- Повышать квалификацию раз в 3 года; работать методически корректно.
- Участвовать в ППк и исполнять решения консилиума в своей части.

## Психолог ВПРАВЕ

- Отказаться от выполнения непрофильных поручений (проверка тетрадей, дежурства сверх локальных норм, замещение уроков вне установленного порядка).
- Не сообщать содержание консультаций администрации и учителям.
- Требовать условия для конфиденциальной работы (кабинет, закрытое хранение).
- Участвовать в защите ребёнка: инициировать ППк, ходатайствовать перед администрацией о мерах поддержки.
- Получать супервизию и методическую помощь (муниципальная психологическая служба, центры ППМС-помощи).

## Психолог НЕ ДОЛЖЕН (ни при каком давлении)

| Нарушение | Почему |
|-----------|--------|
| Ставить диагнозы («ЗПР», «аутизм», «депрессия») | Диагноз — компетенция ПМПК/врача; психолог описывает особенности развития |
| Назначать лечение, препараты, «диагностировать» медикаменты | Врачебная деятельность без лицензии — незаконна |
| Передавать данные о ребёнке без согласия/запроса | Нарушение 152-ФЗ и профессиональной тайны |
| Проводить диагностику без согласия родителей (плановую) | Нарушение ст. 42 273-ФЗ |
| Выполнять функции карательного органа («провести профилактическую беседу, чтобы больше не…») | Разрушает доверие к психологической службе у детей |
| Проводить «тестирование учителей» по заказу администрации для оценки их профпригодности | Не входит в задачи службы; этически недопустимо (исключение — добровольные запросы педагогов о собственном развитии/выгорании) |
| Давать устные «характеристики» детей при приёме в школу, переводе, спорах родителей | Только письменные заключения по запросу в установленном порядке |
| Утаивать сведения об угрозе жизни ребёнка «ради конфиденциальности» | Тайна не абсолютна: приоритет — безопасность |

## Типовые конфликтные ситуации

**«Проведите с ним беседу, он плохо себя ведёт» (администрация).** Ответ: «Встречусь и разберусь, что происходит; если нужна работа с поведением — предлагаю ППк с участием классного руководителя и родителей». Психолог работает с причинами, а не «прессует» за поведение.

**«Дайте список детей группы риска всем учителям».** Списки с ПДн не рассылаются; передаётся обезличенная информация: сколько детей в сопровождении, какие классы нуждаются во внимании, общие рекомендации.

**Родитель требует «рассказать всё, что говорил ребёнок».** Подросток с 15 лет консультируется конфиденциально; родителю — общий план работы и советы, содержание — только с согласия подростка. С младшими — родитель включён в сопровождение активнее.

**«Психолог бездействует — у нас ЧП».** Действуйте по [кризисному алгоритму](/docs/work/krizis) независимо от «разрешений»: безопасность — всегда приоритет; уведомление администрации — обязанность, а не «право».

## Куда обращаться за поддержкой

- Методист/куратор психологической службы муниципального управления образования.
- Территориальный центр ППМС-помощи (в РТ — адреса на [edu.tatar.ru](https://edu.tatar.ru/)).
- Минобрнауки РТ ([mon.tatarstan.ru](https://mon.tatarstan.ru/)) — по вопросам организации службы.
- Профсоюз — при трудовых спорах (нагрузка, оплата).
