# Кризисное реагирование

Острая ситуация — не «обычная консультация»: здесь важны алгоритм, скорость и межведомственное взаимодействие. Ниже — ориентиры; конкретные алгоритмы закрепляются в школе приказами и планами.

## Общий порядок действий

1. **Обеспечить безопасность** — физическую (не оставлять одного при риске) и психологическую (убрать аудиторию, спокойный тон).
2. **Информировать администрацию** — устно сразу, письменно в тот же день (служебная записка).
3. **Уведомить родителей/законных представителей** — лично, документально зафиксировав.
4. **Подключить ведомства** по тяжести случая: медицинская помощь (103/112), КДН, опека, следственные органы — при признаках преступления против ребёнка.
5. **Сопровождение после острого периода**: поддержка ребёнка, класса, учителей; наблюдение динамики через ППк.
6. **Документирование**: всё — в [карте сопровождения](/docs/templates/karta-soprovozhdeniya) и отдельной папке «Кризисное вмешательство» (дата, время, действия, уведомления).

## Суицидальный риск

### Признаки, требующие немедленной реакции

- Прямые или косвенные высказывания о желании умереть, «прощальные» сообщения, раздача ценностей.
- Самоповреждения.
- Резкое изменение поведения на «беспричинно спокойное» после периода подавленности (решение принято).
- Травля, изоляция + депрессивная симптоматика (подавленность, нарушения сна/аппетита, потеря интересов ≥ 2 недель).

### Алгоритм

1. Беседа без обесценивания («не выдумывай», «это грех» — нельзя). Спрашивать о суицидальных мыслях прямо — безопасно: «Бывают мысли, что не хочется жить?».
2. Оценка риска: есть ли план, средства, сроки, попытки ранее.
3. **Немедленно** — информирование родителей и администрации; при высоком риске — вызов скорой (103/112) и решение вопроса о госпитализации; родители обязаны обеспечить обращение к психиатру.
4. При отказе родителей от помощи при явном риске — школа вправе (и обязана) обратиться в органы опеки/КДН: жизнь ребёнка приоритетнее согласия.
5. После острого эпизода: щадящий режим, контакт с психиатром (лечение — вне компетенции школы), работа с классом без подробностей (см. ниже), наблюдение.

### Если произошла попытка / завершённый суицид

- Школа действует по межведомственному алгоритму (в РТ — совместно с Минобрнауки РТ, здравоохранением, СК).
- **В классе**: не собирать «траурные линейки» и не создавать ореол (риск «эффекта Вертера»); формат — короткое обсуждение факта без метода и деталей, нормализация чувств, где получить помощь; работа с близкими друзьями индивидуально.
- Психолог сам получает супервизию/поддержку — это норма, а не слабость.

:::warning Самоповреждения ≠ «манипуляция»
Даже «поверхностные» самопорезы — повод для серьёзного отношения и направления к специалисту, независимо от предполагаемых «мотивов».
:::

## Насилие и жестокое обращение

- Признаки физического/сексуального насилия, пренебрежения: травмы, страх взрослых, сексуализированное поведение не по возрасту, хроническая неопрятность/голод, резкие изменения поведения.
- Беседа — без наводящих вопросов и обещаний «никому не скажу» (вы обязаны сообщить). Фиксация дословно.
- Немедленное информирование директора; при обоснованном подозрении — сообщение в органы опеки, КДН, следственные органы (ст. 121 СК РФ, 120-ФЗ; «Служба Ребёнок в опасности» — 8-800-200-80-02? — используйте актуальный номер вашего региона; экстренно — 112).
- Дальнейшая работа — только в связке с ведомствами; психолог не «расследует».

## Буллинг

1. Прекратить травлю (вмешательство учителя/администрации немедленно).
2. Отдельные беседы: с жертвой (поддержка, безопасность), с агрессорами (не «суд», а ответственность и изменение поведения), с очевидцами (роль свидетелей, как помогать).
3. Работа с классом (программы по профилактике буллинга), информирование родителей обеих сторон.
4. Мониторинг ситуации 1–2 месяца; при необходимости — ППк.

## Утрата (смерть близкого, развод, переезд)

- Разрешить переживание: разговор, ритуалы памяти в приемлемой форме.
- Поддерживающие встречи; наблюдение за динамикой горя.
- Инструктаж классного руководителя: не выделять «особым отношением», но быть доступным.
- Признаки осложнённого горя (более 2–3 месяцев без динамики, симптомы депрессии) — направление к специалисту.

## Телефоны (держите на виду в кабинете)

- 8-800-2000-122 — детский телефон доверия (бесплатно, анонимно, круглосуточно);
- 112 — единый экстренный номер;
- 103 — скорая помощь;
- Служба «Ребёнок в опасности» Следственного комитета РФ — 8 (800) 200-19-10? — сверяйте актуальный федеральный номер на официальном сайте СК; региональные номера — на сайте СК по РТ.
