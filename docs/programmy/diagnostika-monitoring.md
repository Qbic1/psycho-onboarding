# Программа 2. Психолого-педагогическая диагностика и мониторинг развития

Мониторинг — информационный фундамент всех остальных программ: без объективных данных диагностики не выстраиваются коррекция, профилактика и сопровождение групп риска.

## Правовые основы

- Федеральный закон от 29.12.2012 № 273-ФЗ «Об образовании в Российской Федерации» (ст. 42).
- ФГОС НОО, ООО, СОО — системная оценка личностных и метапредметных результатов освоения ООП.
- Распоряжения Минпросвещения России от 28.12.2020 № Р-193 (система функционирования психологических служб) и от 09.09.2019 № Р-93 (примерное положение о ППк).
- Приказ Минпросвещения России от 24.09.2021 № 637 — порядок [социально-психологического тестирования](/docs/work/spt); письмо Минпросвещения России от 28.07.2023 № 07-4251 — психолого-педагогический скрининг.
- Федеральный закон от 27.07.2006 № 152-ФЗ «О персональных данных».
- Республика Татарстан: приказ МОиН РТ от 20.04.2023 № под-851/23 — порядок мониторинга безопасности образовательной среды (МБОС); приказы МОиН РТ о проведении СПТ и МБОС в текущем учебном году.

## Терминология

- **Мониторинг** — систематическое отслеживание показателей развития по единым параметрам с сравнимыми «срезами».
- **Скрининг** — краткое охватное обследование всей параллели для первичного выявления группы риска.
- **УУД (универсальные учебные действия)** — личностные, регулятивные, познавательные, коммуникативные; предмет психологического мониторинга в логике ФГОС.
- **Фронтальная / индивидуальная диагностика** — обследование целого класса / углублённое обследование конкретного ребёнка.
- **СПТ** — социально-психологическое тестирование обучающихся 7–11 классов (с 13 лет, добровольно, ежегодно).
- **МБОС** — мониторинг безопасности образовательной среды (в РТ — 6–11 классы, два этапа в год, онлайн).
- **Диагностическая карта** — сводка результатов обследований ребёнка за год (см. [Карта сопровождения](/docs/templates/karta-soprovozhdeniya)).

## Актуальность

Мониторинг обеспечивает индивидуализацию образовательного процесса: показывает, каким детям нужны коррекционные занятия, профилактическая работа или углублённая диагностика. Регулярные срезы сентября и мая позволяют объективно доказать эффективность работы психологической службы администрации и вышестоящим органам. Обязательные федеральные и региональные процедуры (СПТ, МБОС) встроены в единый мониторинговый цикл.

## Цели и задачи

**Цель:** организация систематического психолого-педагогического мониторинга личностных, регулятивных, познавательных и коммуникативных особенностей обучающихся 1–11 классов для индивидуализации образовательного процесса.

**Задачи:**

1. Ежегодная диагностика личностных УУД (самооценка, мотивация, ценностные ориентации).
2. Диагностика регулятивных УУД (произвольность, самоконтроль, целеполагание).
3. Диагностика познавательных УУД (внимание, память, мышление, темп деятельности).
4. Диагностика коммуникативных УУД (взаимодействие, статус в коллективе).
5. Формирование аналитических материалов для администрации, педсовета, ППк.
6. Определение обучающихся, нуждающихся в дополнительном сопровождении.

## Описание работы

Диагностика ведётся блоками по учебному году (фронтально, по параллелям), плюс обязательные процедуры:

| Блок | Примерные сроки | Инструментарий |
|------|-----------------|----------------|
| Личностная сфера | сентябрь – октябрь | Самооценка Дембо – Рубинштейн; мотивация М.Р. Гинзбурга; «Незаконченные предложения»; анкеты удовлетворённости |
| Адаптация (1, 5, 10 кл.) | сентябрь – октябрь | По программе 1 [адаптации](/docs/programmy/adaptaciya) |
| СПТ (7–11 кл.) | 15.09 – 15.10 | Единая федеральная методика, порядок [СПТ](/docs/work/spt) |
| Регулятивная сфера | октябрь | «Графический диктант» Д.Б. Эльконина (1–4 кл.), самоконтроль и планирование (5–9 кл.), волевая саморегуляция (10–11 кл.) |
| Познавательная сфера | ноябрь | Тест Тулуз-Пьерона, таблицы Шульте; «10 слов» А.Р. Лурии; мышление (аналогии, классификации) |
| МБОС 1 этап (6–11 кл.) | ноябрь | Онлайн-тестирование по порядку МОиН РТ |
| Коммуникативная сфера | ноябрь – декабрь | Социометрия Дж. Морено; наблюдение; анкетирование педагогов |
| Аналитика I полугодия | январь | Обработка, сводные таблицы, справки для педсовета |
| Скрининг II полугодия | февраль | Межличностные отношения, климат, риски травли (опросник риска буллинга А.А. Бочавер и соавт.) |
| МБОС 2 этап | апрель | Онлайн-тестирование |
| Итоговый срез | май | Ключевые параметры, индивидуальные диагностические карты, годовая справка |

Формы: фронтальная и индивидуальная диагностика, компьютерное тестирование, наблюдение в естественных условиях, аналитическая работа. Углублённая индивидуальная диагностика — только с письменного согласия родителей (обучающегося с 15 лет).

## Взаимодействие со специалистами

### Внутри учреждения (воспитательный штаб)

- **Классные руководители** — график проведения, организованность класса, экспертные оценки рисков, доведение рекомендаций.
- **Учителя-предметники** — экспертные оценки, наблюдение учебной деятельности.
- **Заместитель директора по ВР** — координация СПТ и МБОС (приказ по школе, инструктажи, контроль охвата).
- **Администрация / педагогический совет** — получатели аналитических справок; принятие управленческих решений по итогам.
- **ППк** — рассмотрение результатов углублённой диагностики, маршрутизация детей.

### Межведомственное взаимодействие

- **Региональный оператор СПТ** — передача результатов тестирования по установленному порядку.
- **ГАОУ ЦППРК «Росток»** — методики МБОС, обработка и передача списков группы риска по итогам мониторинга; методическая поддержка.
- **Территориальная ПМПК** — материалы углублённой диагностики при направлении детей.
- **МОиН РТ / Управление образования** — отчётность по установленным формам.

## Примерные сроки: помесячный план

| Месяц | Мероприятия |
|-------|-------------|
| **Сентябрь** | График скринингов и комплектование групп; согласия; старт личностного блока; подготовка и старт СПТ (согласия до 15.09, тестирование с 15.09) |
| **Октябрь** | Завершение СПТ (до 15.10) и передача результатов; регулятивный блок; углублённая диагностика по показаниям скрининга |
| **Ноябрь** | Познавательный блок; МБОС 1 этап; коммуникативный блок начинается |
| **Декабрь** | Социометрия по всем параллелям; обобщение результатов полугодия |
| **Январь** | Обработка и систематизация I полугодия; аналитические справки для администрации и педсовета |
| **Февраль** | Плановый скрининг II полугодия (климат, межличностные отношения, травля) |
| **Март** | Анализ скрининга; подготовка МБОС 2 этапа; углублённая диагностика по показаниям |
| **Апрель** | МБОС 2 этап; итоговые срезы по программам сопровождения |
| **Май** | Весенний срез ключевых параметров; сопоставление с сентябрём; индивидуальные диагностические карты группы риска; годовая справка |

## Ожидаемые результаты

- Актуальная диагностическая база данных по всем классам на конец года.
- Своевременное выявление (ориентир — не менее 90%) обучающихся с трудностями развития.
- Положительная динамика показателей УУД по сравнению срезов сентября и мая.

:::tip Начинающему психологу
Держите единый график диагностики: без него в октябре – ноябре столкнутся СПТ, адаптационная диагностика и плановые скрининги. Результаты любого скрининга — обезличенно на уровне класса, персональные данные — только в закрытых материалах. Подробнее — [Диагностика](/docs/work/diagnostika) и [персональные данные](/docs/documents/personal-data).
:::
