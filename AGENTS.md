# Правила работы агентов в этом репозитории

## Внесение изменений (обязательно)

Любое изменение — контент, код, дизайн, конфигурация — вносится только через pull request:

1. Создать отдельную ветку от `main`: `content/<тема>`, `design/<тема>`, `fix/<тема>`.
2. Зафиксировать изменения в ветке и запушить её в origin.
3. Открыть pull request в `main` с внятным описанием сути изменения.
4. Дождаться подтверждения автора репозитория (approving review) — только после этого мерж.

Прямые пуши в `main` запрещены (branch protection: pull request + 1 одобрение). Автор PR не одобряет и не мержит его сам без явного подтверждения автора репозитория.

## Дизайн

Дизайн-изменения согласуются с `DESIGN.md` (дизайн-система «Хвойная зелень», North Star «Рабочий кабинет») и `PRODUCT.md`. В проекте установлен Impeccable (`.github/skills/impeccable`): хуки автоматически проверяют UI-правки на типовые AI-паттерны, CLI — `.github\skills\impeccable\scripts\impeccable.cmd <команда>`.

## Деплой

Мерж в `main` автоматически публикует сайт на GitHub Pages (`.github/workflows/deploy.yml`). Перед мержем убеждайтесь, что `npm run build` проходит локально.
